# חמישה ימים בדולומיטים

עמוד תכנון לטיול בדולומיטים, 6 עד 10 בספטמבר 2026, מבסיס בסיוזי (Siusi / Seis am Schlern).
מסודר לפי נושאים: פסגות ורכבלים, אגמים, מסלולי הליכה, שקיעות, כפרים וספא.

אתר סטטי, קובץ אחד. אין תלויות ואין שלב בנייה.
